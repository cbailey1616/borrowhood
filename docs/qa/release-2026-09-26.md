## Included

- GitHub-inspired Borrowhood sign-in form, prominent branding, compact Face ID,
  balanced Google/native Apple controls, and password recovery.
- Three-step onboarding: name/town, optional neighborhood join/create, optional
  Stripe verification. Empty-neighborhood state, retries, skip, and resume.
- Green verification action, official purple Stripe logo, and an accessible
  comparison pop-up. No privacy footer below Not now; no data-retention change.
- Compact explanation that verified profile name/location are locked.
- Colorful themed activity icons, with distinct question/reply/rank symbols.
- Feed pagination/recovery, bounded ranking, incremental rank notifications,
  background database isolation, database-aware health and private-photo logs.
- Screenshot fixtures with fictional member portraits and a My Neighborhood
  scene. Promotional downloads are separate review assets, not an App Store
  metadata upload.

- Mobile: 1,366/1,368 passed on the full run; two stale text expectations were
  fixed and all 27 tests in the affected suites passed on rerun.
- Server: all 466 privacy/reliability tests passed. The full local command then
  stopped because native PostgreSQL tools were unavailable, without accessing
  a database. Native API/migration/traffic/restore checks are required in CI.
- Production iOS JavaScript/assets export passed. Diff whitespace check passed.
- The CI workflow repeats all mobile tests, iOS export, native database checks,
  launch traffic and isolated native backup restoration before signed release.
- The release workflow allocates the next unused iOS build number and audits
  the signed archive before submitting it to TestFlight.

## Device acceptance and launch follow-up

Check small iPhones/large text, keyboard and safe-area behavior, Apple/Google/
Face ID sign-in, real Stripe return, neighborhood create/join/skip, and restored
setup progress on the compiled app. Existing accounts must open the main app.
Realistic Railway staging load, a hosting backup restore, actual alert delivery,
private-photo diagnostics and push delivery remain launch-readiness follow-ups;
the local synthetic traffic results do not establish production capacity.
