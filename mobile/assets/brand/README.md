# Sign-in brand assets

These provider marks retain their official appearance. Borrowhood's woodland illustration system is used for app actions, not third-party brand identities.

- `google-g.png`: official Google G, downloaded from https://developers.google.com/static/identity/images/g-logo.png. Used only on the Google authentication button, following https://developers.google.com/identity/branding-guidelines.
- `GoogleSans-Medium.ttf`: Google Sans, weight 500, subset to Latin and punctuation for the English sign-in label; obtained through https://fonts.googleapis.com/css2?family=Google+Sans:wght@500. Copyright 2025 The Google Sans Project Authors (https://github.com/googlefonts/googlesans); distributed under the SIL Open Font License in `GoogleSans-LICENSE.txt`.
- Apple uses the native `expo-apple-authentication` button with its supported white outline style and rounded corners.
